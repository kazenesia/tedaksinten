Generator Link Undangan

Tempel daftar nama tamu (satu nama per baris), lalu salin link personalnya atau kirim langsung via WhatsApp.

NamaLink
Cara pakai: upload folder undangan ke hosting (Netlify / Vercel / GitHub Pages / cPanel), ganti URL di atas dengan domain Anda, lalu bagikan link per tamu. Format link yang dihasilkan: https://domain.com/?to=Hari%20Maulana. Tanpa parameter ?to=, tamu tetap bisa mengisi namanya sendiri di halaman sampul.
